# Product Roadmap

This roadmap is outcome-based. Dates remain `TBD` until research capacity and release targets are agreed.

| Milestone | Outcome | Key evidence | Exit gate |
| --- | --- | --- | --- |
| M0 - Concept | Establish the room metaphor and product boundary | PRD and interaction mapping | Completed |
| M1 - Functional MVP | Demonstrate the complete record/reflection loop locally | Build QA and acceptance criteria | Implemented; user validation pending |
| M2 - Research Beta | Learn whether the metaphor is understandable, supportive, and useful over repeated use | Moderated tests plus short diary study | Critical usability and trust findings addressed |
| M3 - Private Alpha | Add privacy controls and optional account/sync foundation | Security review, export/delete tests, sync conflict tests | No critical data-loss/privacy risks |
| M4 - Personalized Room | Add validated object-native UI and selected customization | Experiment results and retention signals | Customization improves meaning without distraction |

## M2 Candidate Scope

- First-user onboarding revision based on research
- Automated task/carryover tests
- Data export and delete controls
- Explicit Mirror context selection/consent
- Accessibility audit and fixes
- Instrumented, privacy-conscious usability metrics

## Decision Gates

1. Keep or revise furniture mappings after five representative usability sessions.
2. Keep Life Novel in the main loop only if users understand and value approved narrative drafting.
3. Add cloud sync only after ownership, deletion, encryption, and conflict behavior are specified.
4. Explore rotation, music, Focus Mode, and store only after the core reflection loop is validated.
