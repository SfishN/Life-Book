# User Journey - MVP

## Primary User

A person who wants a gentle way to notice, record, and improve their life without feeling judged by a productivity system.

## Job to Be Done

When I want to understand how I am living and growing, I want one calm place where plans, actions, reflections, and memories connect, so I can see progress without turning life into a game.

## Core Journey

| Stage | User goal | Room action | System response | Desired feeling |
| --- | --- | --- | --- | --- |
| Arrive | Reorient without pressure | Enter the fixed room | Show the character, room, and simple controls | Safe and curious |
| Choose direction | Name what matters | Open the Vision Board | Create or review up to three Main Quests | Focused |
| Identify growth | Connect action to capability | Open the Plant | Add or review a Skill | Hopeful |
| Plan | Define the next small action | Open the Desk or Calendar | Save one shared task record | Capable |
| Return | Continue after interruption | Re-enter on a later day | Show unfinished work as carried forward without duplication | Welcomed, not blamed |
| Act and record | Mark real progress | Complete a task | Offer a Success Diary entry and add room memory feedback | Recognized |
| Reflect | Understand meaning | Speak with the Mirror | Respond as a friend/observer and suggest, never decide | Accompanied |
| Confirm growth | Keep only what feels true | Review Skill or Achievement candidate | Save only user-confirmed meaning | In control |
| Build narrative | See life over time | Open the Room/Life Novel | Draft from approved records and require approval | Coherent |

## Alternate Journeys

### Calendar-first planning

The user selects a date, writes an annotation, creates or edits a task, adds a diary entry, and opens the complete Desk view. Calendar and Desk must show the same record.

### AI unavailable

The Mirror uses a transparent local observer response. All other recording features remain usable.

### Keyboard-free or touch use

The user taps an object directly or uses the Room index. Character movement must not be the only way to reach a feature.

### Offline return

Previously loaded room assets and browser-local records remain available. The UI must not imply cloud backup when none exists.

## Journey Questions for Research

- Do users understand the furniture mapping without instructions?
- Does the room feel calmer than a conventional dashboard?
- Is carried-forward wording supportive rather than shaming?
- Do users understand that the Mirror suggests but does not define them?
- Does the Life Novel feel meaningful or premature during early use?
